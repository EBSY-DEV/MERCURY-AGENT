Follow-ups

How steps 2 and 3 of a sequence go out with Gmail or SMTP. Saved to channels.email.thread_followups.

On: each follow-up replies to the email before it, under the first email's subject with "Re:" in front, so the recipient sees one conversation. Off: each step goes out as a new email with its own subject.

What is Mercury Agent?

Mercury Agent is an autonomous outreach agent. Once set up, Mercury runs on its own: finds people who match your ideal customer, writes personalized cold emails, sends them through your email platform, reads every reply, handles objections, and works toward booking a meeting. You review everything through this dashboard.

Mercury runs on your Claude Max subscription, so there are no extra AI costs. Everything stays on your machine in one folder.

Getting Started

There are four things to do:

1. Settings: connect an email provider (Gmail recommended) and a verifier key
2. Train Mercury on your product (mercury train <your-site>)
3. Signals: confirm what defines a good prospect
4. Open controls from the sidebar and click Start

The Setup card on Today shows exactly what's done and what still needs to happen.

Where Everything Lives

Everything Mercury needs is inside this one project folder. Nothing is stored elsewhere.

Getting Your API Keys

Instantly API Key (required)

Instantly is the email platform Mercury uses to send campaigns.

1. Sign up at instantly.ai (you need the Growth plan for API access)

2. Go to Settings > Integrations

3. Copy your API key

4. Paste it in the Settings tab here

LinkedIn Credentials (optional)

If you want Mercury to find prospects on LinkedIn, enter your LinkedIn email and password. Mercury uses a real browser to search LinkedIn like a human would, with random delays and rate limits to avoid detection.

If you skip this, Mercury will find prospects through Google searches and company website scraping instead.

Cloudflare Browser Rendering (optional)

This is only used during product training (when Mercury crawls your website to learn about your product). It handles JavaScript-heavy websites that a basic crawler can't read.

1. Sign up at Cloudflare (paid Workers plan, ~$5/month)

2. Go to Workers & Pages > Browser Rendering

3. Create an API token with Browser Rendering Edit permissions

4. Enter your Account ID and API Token in the Settings tab

Without this, Mercury uses a built-in crawler that works fine for most websites but can't render JavaScript.

Common Issues

"command not found: mercury"
You need to activate the virtual environment first: source .venv/bin/activate
Instantly API returns 401
Your API key is wrong, or you need the Growth plan (the free plan doesn't include API access). Double-check the key in Settings > Integrations in your Instantly dashboard.
Claude headless mode fails
Make sure you've run claude login in your terminal and have an active Claude Max subscription. Mercury uses your existing subscription, not a separate API key.
Mercury isn't finding prospects
Check that your ICP (ideal customer profile) in mercury.yaml has realistic titles, industries, and geography. If LinkedIn is set up, check that the credentials are correct. Check the Activity tab to see what Mercury has been trying to do.
