# Persona avatars

These 24 SVGs were generated with the DiceBear 10.x **Critters** style.
Source: https://www.dicebear.com/styles/critters/
Style license: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/

Each filename is its seed. The source URL is:
`https://api.dicebear.com/10.x/critters/svg?seed=mercury-persona-NN`
where NN ranges from 01 to 24.

The frozen SVGs are bundled with Mercury so avatars work offline and stay
unchanged when the upstream generator changes. Creating or shuffling a
persona chooses from this local collection; no network request is made.
